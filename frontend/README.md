# Frontend

React + TypeScript + Ant Design, built with Vite. Run via the root [`README.md`](../README.md) (`cd docker && docker compose up --build`) — this app isn't meant to be run standalone outside the Docker Compose stack.

Scripts (see [`package.json`](package.json)): `dev`, `build`, `lint` (oxlint), `type-check` (`tsc -b`), `test` (vitest).
