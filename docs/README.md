# Docs

- `architecture/` — how the system is built: overview plus a decision log (ADRs) for significant, hard-to-reverse technical choices.
- `modules/` — one folder per business module, holding that module's functional/business specification.

Permanent engineering and product principles that apply across all modules live in the root [`CLAUDE.md`](../CLAUDE.md), not here. This folder is for the specifics: what a given module does, and why a given technical decision was made.
