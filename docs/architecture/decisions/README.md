# Architecture Decision Records

One file per significant decision: `NNNN-short-title.md`, numbered sequentially. Start from [`0000-template.md`](0000-template.md).

A decision is worth recording here if it would be expensive to reverse, or if a future contributor would reasonably ask "why was it done this way?" Day-to-day implementation choices don't need one.

Status values: `proposed`, `accepted`, `superseded by NNNN`.
